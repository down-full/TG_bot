# 🤖 Валютник

Telegram-бот для отслеживания валюты разными способами.

## ✨ Функциональность

- 🛠 Возможность конвертации валют
- 🛠 Просмотр курса к доллару
- 🛠 Возможность добавить курс в избранное  
- 🛠 Создание уведомлений на изменение курса
- 🛠 Просмотр динамики с графиком за кастомный период

## 🚀 Начало работы
1. Найдите в Telegram: `@rate144_bot`
2. Нажмите **/start**

### 🎯 Основные команды и Доступные команды
Просто отправьте одну из команд в чат с ботом:

### 📋 Список

|   Команда  |                     Описание                        |
|------------|-----------------------------------------------------|
| `/start`   | Запустить бота и получить приветствие               |
| `/help`    | Показать справку по всем командам или на конкретную |
| `/authors` | Показать авторов                                    |
| `/rate`    | Показать курс нескольких валют или одной            |
| `/convert` | Конвертировать суммы                                |
| `/fadd`    | Работа с избранными валютами                        |
| `/notify`  | Управление уведомлениями                            |
| `/chart`   | Вывод графика динамики                              |
| `/about`   | Описание                                            |


### Конвертация 💶 -> 💵

- **`/convert <сумма> <из валюты> <в валюту>`** - Перевод суммы из одной валюты в другую.  
- *Пример:* `/convert 100 RUB USD`

### Курсы относительно RUB 💸
- **`/rate <валюта> - курс конкретной валюты`** - Выдает курс конкретной валюты к рублю: 1 EUR = 89,10 RUB
- *Пример:* `/rate EUR`
- **`/rate`** - Показать список всех курсов к рублю
- *Пример:* `/rate`

### ⚙ Создание уведомлений ✉️
- Их можно создать только 10 штучек
- **`/notify set <валюта> <(<=, >=)> <порог> - установка уведомления`** - Установит уведомление об изменении.
- *Пример:* `/set USD >= 90`
- **`/notify clear <валюта>`** - Удаляет конкретное уведомления для валюты
- *Пример:* `/notify clear USD`
- **`/notify clear <all>`** - Удаляет все уведомления
- **`/notify status`** - Список всех уведомлений

### 💹 Просмотр динамики  💹
- Возможность вводить кастомные периоды, но нельзя просмотреть за один день.
- Распознавание по диапазонам (ДАТА): 
- **разные форматы дат: |dd.MM.yyyy|-|yyyy-MM-dd|-|dd.MM.yy|-|dd/MM/yyyy|-|dd-MM-yyyy|**
- **слова: сегодня/today, месяц назад/last month, полгода назад/last half year, год назад/last year**
- **названия месяцев (пример): янв, январь, января, jan, january. В зависимость от того ставить число перед или нет, т.е.**
- **1 | янв/.../ | 2023  или | без числа | май 2023**
- **`/chart <Из валюты> <В валюту> <Дата от> <Дата до>`** - Выдаст изображение графика.
